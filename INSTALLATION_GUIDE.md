# Secure SFTP Client - Installation Guide

## 📦 What's Included

This installer package contains the **Secure SFTP Client** - a modern, user-friendly application for secure file transfers over SFTP.

## ✨ Features

- **Secure SFTP Connections**: Connect to SFTP servers with full encryption
- **Modern GUI**: Clean, intuitive interface built with CustomTkinter
- **File Management**: Upload, download, and manage files easily
- **Drag & Drop Support**: Intuitive file operations
- **Connection Management**: Save and manage multiple server connections
- **Cross-Platform**: Works on Windows, macOS, and Linux

## 🚀 Installation Instructions

### System Requirements
- **Windows 10/11** (64-bit)
- **Administrator privileges** (required for installation)
- **Internet connection** (for initial setup)

### Installation Steps

1. **Download the Installer**
   - Get `SecureSFTPClient_Installer.exe` from the provided location

2. **Run the Installer**
   - Double-click `SecureSFTPClient_Installer.exe`
   - Click "Next" to proceed through the installation wizard
   - Choose your installation directory (default: `C:\Program Files\SecureSFTPClient`)
   - Click "Install" to complete the installation

3. **Launch the Application**
   - After installation, you can launch the application from:
     - **Desktop shortcut** (if you selected this option)
     - **Start Menu** → Secure SFTP Client
     - **Installation folder** → SecureSFTPClient.exe

## 🔧 First-Time Setup

1. **Launch the Application**
   - Click the desktop shortcut or start menu entry

2. **Add a Server Connection**
   - Click "Add Server" or use the connection menu
   - Enter your SFTP server details:
     - **Host**: Your SFTP server address
     - **Port**: Usually 22 (default SFTP port)
     - **Username**: Your SFTP username
     - **Password**: Your SFTP password
   - Click "Connect" to establish the connection

3. **Start Transferring Files**
   - Browse local files on the left panel
   - Browse remote files on the right panel
   - Drag and drop files to transfer them
   - Or use the transfer buttons

## 📋 Troubleshooting

### Connection Issues
- **Cannot connect to server**: Verify the host address, port, and credentials
- **Connection timeout**: Check your internet connection and firewall settings
- **Authentication failed**: Ensure your username and password are correct

### File Transfer Issues
- **Permission denied**: Check file permissions on the remote server
- **Disk space**: Ensure you have enough disk space for downloads
- **Network interruption**: Check your internet connection

### Application Issues
- **Application won't start**: Try running as Administrator
- **GUI display issues**: Update your graphics drivers
- **Performance issues**: Close other applications to free up system resources

## 🔐 Security Notes

- **Credentials**: Your connection credentials are stored locally and encrypted
- **SFTP Protocol**: All file transfers use secure SFTP protocol (SSH-based)
- **SSL/TLS**: Supports modern encryption standards
- **No Cloud Storage**: All data remains on your local machine and the remote server

## 📞 Support & Feedback

## 🗑️ Uninstallation

To remove the application:
1. Go to **Control Panel** → **Programs** → **Programs and Features**
2. Find "Secure SFTP Client" in the list
3. Click "Uninstall" and follow the prompts
4. Or use the "Uninstall" shortcut from the Start Menu
